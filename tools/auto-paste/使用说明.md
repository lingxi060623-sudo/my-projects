# 自动粘贴

模拟键盘一个字一个字地把文字"打"进当前窗口。专门对付不让粘贴的地方：网课 / 考试系统的输入框、头歌等在线编辑器、虚拟机控制台、远程桌面等。

双击 `自动粘贴.exe` 就能用，不用安装（Windows 10/11 自带所需的 .NET Framework）。不联网，不收集任何数据。

## 最常用的用法

1. 复制要输入的文字（Ctrl+C）
2. 在目标输入框里点一下，让光标停在那里
3. 按 **Ctrl + Alt + V**，倒计时结束后开始自动输入
4. 想中途停下：按 **Esc**，或者再按一次快捷键

也可以点窗口里的「开始输入」按钮，然后在倒计时（至少 3 秒）里点一下要输入的位置。

屏幕顶部会出现一个小黑条，显示倒计时和进度；它不会抢焦点，也不挡鼠标。

## 各项设置

| 设置 | 说明 |
| --- | --- |
| 要输入的内容 | 「剪贴板」：按快捷键时读取剪贴板，界面里实时预览；「自定义」：自己在框里写好要输入的内容 |
| 快捷键 | 点一下快捷键框，再按新的组合（要带 Ctrl 或 Alt，F1–F12 可以单独用）。按 Esc 取消 |
| 开始前倒计时 | 按下快捷键后等几秒再开始，0 表示松开快捷键就开始 |
| 每字间隔 | 每打一个字停多少毫秒。目标程序漏字、乱序时调大一点（比如 20–50） |
| 输入方式 | **Unicode**（默认）：直接发送文字，绝大多数软件都能用，打中文不用切输入法。**按键模拟**：模拟真实的物理按键，给虚拟机、远程桌面、部分游戏用，开始前会自动关掉中文输入法，结束后恢复 |
| 换行方式 | **回车**：正常换行；**Shift+回车**：在微信、QQ 这类"回车就发送"的地方换行；**忽略**：不换行 |
| 代码编辑器修正 | 给头歌等在线代码编辑器用：编辑器会自动补右括号、引号和缩进，打进去的代码会多出东西。打开后会自动抵消这些补全。请在**空白**编辑器里使用 |
| 置顶 | 让窗口一直浮在最上面 |

设置会自动保存在 `%APPDATA%\自动粘贴\settings.ini`。

## 小提示

- 文字末尾的换行不会输入，免得在聊天框、表单里误发送、误提交。
- 输入过程中如果你切到了别的窗口，会自动停止，不会打到别处去。
- 目标程序是"以管理员身份运行"的话，要把本工具也右键「以管理员身份运行」才能输入进去。
- 某些虚拟机、远程桌面收不到 Unicode 文字，这时把输入方式换成「按键模拟」。按键模拟只能可靠地输入键盘上有的字符（英文、数字、符号）。

## 从源码重新编译

双击 `build.bat`，会用 Windows 自带的 C# 编译器在当前文件夹生成 `自动粘贴.exe`。

| 文件 | 内容 |
| --- | --- |
| `src\Typer.cs` | 输入引擎：用 SendInput 发送 Unicode 文字或扫描码按键 |
| `src\MainForm.cs` | 主窗口、全局快捷键、Esc 停止 |
| `src\Controls.cs` | 自绘的界面控件（分段按钮、开关、数字框、快捷键框等） |
| `src\Hud.cs` | 屏幕顶部的进度条 |
| `src\Settings.cs` | 设置的读写 |
| `tools\MakeIcon.cs` | 生成 `src\app.ico` 图标（删掉图标后重新编译会自动生成） |
